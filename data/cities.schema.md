# 城市数据源说明 · 怎么增加一座城市

工作台里**所有行程内容都来自 `data/cities.js`**，页面本身不再内嵌任何城市数据。
运行时只认一个数组 `D`：内置城市 + 本机自定义城市叠加后交给全站渲染。
新增城市**不需要改任何渲染 / 路线 / 地图 / 视频代码**。

---

## 三种新增方式

| 方式 | 适合 | 生效范围 |
|---|---|---|
| ① **页面「✨ 快速新增」向导（推荐）** | 任何人，填城市名 + 几个落点 | 只存这台设备的 localStorage |
| ② 编辑 `data/cities.js` 的 `extended` 数组 | 仓库维护者，要全站共享 | 所有访客，提交后重新部署 |
| ③ 把导出的 JSON 交给 CI 合并 | 从本机草稿变成正式数据 | 所有访客 |

推荐流程（最省事）：**先用向导在页面上试 → 确认逐日路线 / 衣食住行 / 视频分镜都有内容 → 点「↓ 导出全站内容包 cities.js」→ 直接覆盖仓库 `data/cities.js` → `git push` → Pages 自动重新部署**。

> 「↓ 导出自定义城市 JSON」只给草稿数组，需要人工合并；
> 「↓ 导出全站内容包」给的是**可直接覆盖的 `cities.js` 文件**（`window.XINGJI_CITIES = {...}`），
> 内置城 / 扩展城 / 自定义城 / 大区顺序全都在里面，不用手工拼。
>
> 完整的数据来源、字段如何变成画面与字幕、Pages 部署闭环见
> **[数据链路与内容配置.md](../数据链路与内容配置.md)**。
> 成片栏目（衣食住行各显示哪些字段、口播怎么拼）由 `config.js` 的
> `XINGJI_PLAN_CONFIG` 决定，不在这个文件里。

### 向导会自动生成「规划内容」，不是只加个名字

向导把用户填的少量信息展开成完整城市对象，保证 `buildRoute()` 排满所选天数：

| 输入 | 自动展开 |
|---|---|
| 城市名 | `intro` / `tags` / `tag` / `en` / `id` / 主题色 / 示意中心坐标 |
| 落点名（一行一个，可写 `名称 \| 区域`） | `spots` 补足到 `max(12, min(24, 天数×3+3))` 个，自动分配区域 / 时长 / 票价 / 标签 / 亮点 |
| 美食 / 住宿（可留空） | `food` 至少 6 组、`stay` 至少 3 个区域 |
| 气候带 | `clothes`（分季穿搭）、`budget` 三档、`seasons`、`climate`、`transport` 4 条 |

**诚实口径**：补位落点是「老城街区 / 滨水步道 / 本地市集」这类**通用场景**，亮点文案带
`【通用建议】` 前缀并写明"不是具体景点名称，出行前请换成当地实际地点"。它们不是伪造的真实景点。
用户填写的落点优先、保留原名，文案提示"建议出行前核对开放时间与票价"。

生成后页面会**立刻切到该城市并跳到「路线规划」页**，弹窗里显示「几天路线 / 几个落点（你填 x 个 + 通用建议 y 个）/ 几组美食 / 几个住宿区」。
实测 7 天经典档：24 个落点、7 天每天 3 个真实安排、无留白。

### JSON 高级入口还在

弹窗第二个 tab「⚙ JSON 高级」保留批量导入、上传文件、下载模板、逐条校验。
**注意**：手写 JSON 若只给少量 `spots`，`buildRoute()` 会用「延伸日 / 留白」补空，看起来就像没有规划内容 —— 要完整行程请用向导。

## 文件结构

```js
window.XINGJI_CITIES = {
  version: 1,
  baseDate: '2026-11-09',
  curated:  [ /* 8 座精选城：spots 已带真实经纬度，自带 clothes / sources */ ],
  extended: [ /* 其余城市：spots 用六项简写，经纬度由 normalizeCity() 推算 */ ],
  regionOrder: ['华北','东北','华东','华中','华南','西南','西北']
};
```

- `curated` 与 `extended` 的唯一区别是 spots 格式；都能用。
- `regionOrder` 只决定大区筛选按钮的**顺序**。自定义城市若填了新 `region`，会自动追加到末尾，不用改这里。
- 页面启动时按 `curated → extended → 自定义城市` 顺序叠加，全部经 `normalizeCity()` 补齐 `clothes` / `sources`（精选城自带，不覆盖）。

## 字段表

### 必填（缺任意一个会被明确拒绝，不会静默出错）

| 字段 | 类型 | 说明 |
|---|---|---|
| `id` | string | 小写字母 / 数字 / `-` `_`，2–32 位，全站唯一 |
| `name` | string | 城市名，如「绍兴」 |
| `prov` | string | 省份 |
| `region` | string | 大区；不在 `regionOrder` 里会自动新增筛选按钮 |
| `center` | `[lat, lng]` | 两个数字，用于推算景点经纬度、地图投影 |
| `tag` | string | 一句话定位，侧栏与封面会显示 |
| `intro` | string | 总览页大段描述 |
| `tags` | string[] | 特色标签，参与侧栏搜索 |
| `budget` | `[经济, 舒适, 品质]` | 三个数字，人均每天参考；三档预算都读它 |
| `climateZone` | string | 见下方枚举；决定「衣」分镜与穿搭文案 |
| `spots` | array | 景点，见下方格式 |
| `food` | array | 美食，见下方格式 |
| `stay` | array | 住宿区域，见下方格式 |
| `transport` | string[] | **至少 4 条**交通提示（页面会读 `[0]` `[1]` `[3]`） |

### 可选（不填会自动补默认值）

| 字段 | 默认值 |
|---|---|
| `en` | `CUSTOM · CITY` |
| `emoji` | `📍` |
| `g` | `['#3f6f63','#8fb3a1']`（封面渐变两端） |
| `a` | `#3f6f63`（主题色） |
| `seasons` | `四季皆宜` |
| `days` | `3 – 4 天` |
| `climate` | `请按当地气候填写` |

### 由代码派生，**不要手写**

- 景点经纬度：`normalizeCity()` 依 `center` 按黄金角散开，`dayTrip` 标签的点会放远并标虚线圈
- `clothes`：由 `climateZone` 从气候模板生成
- `sources`：由城市名 + 大区自动生成 4 条官方检索入口

## 数组格式

```js
spots: [
  // [名称, 区域, 建议时长, 参考票价, 标签(竖线分隔), 一句话亮点]
  ['鲁迅故里','越城区','2h','免费','culture|walk|photo','百草园与三味书屋连成一片，免费预约']
]
food: [
  // [名称, 描述, 去哪吃, 参考人均]
  ['黄酒','温饮最宜，配茴香豆','仓桥直街','¥25']
]
stay: [
  // [区域, 为什么住这, 价位区间, 适合谁]
  ['仓桥直街','老街步行可达','¥180–500','首次到访']
]
transport: [
  '🚄 抵达：绍兴北站',   // [0] 抵达方式，"行"卡片与文稿会引用
  '🚗 市内步行 + 打车',  // [1] 市内交通，讲解词会引用
  '🕐 热门景点需预约',
  '☀️ 梅雨季备伞'        // [3] 总览页提示语
]
```

标签建议从这些里取，路线编排与天气避让会读：
`must / food / photo / shop / museum / history / rain / nature / view / walk /
dayTrip / culture / local / night / kid / art / sport / show`。
`rain` 会被雨天自动避让优先选中，`dayTrip` 会在地图上标为远郊。

## `climateZone` 枚举

`north` / `northeast` / `south` / `coastal` / `plateau` / `tropical` / `northwest`

填错会被拒绝并列出可选值。

---

## 校验规则（在页面里即时反馈）

- 不是对象 / 缺必填字段 / `id` 非法或与已有城市重复 → 明确报错，**不写入**
- `center` 不是两个数字、`budget` 不足三项、`spots` 为空或某条不足 6 项 → 报错
- `food` / `stay` / `transport` / `tags` 不是数组 → 报错
- 批量导入时逐条校验，成功几座就写几座，失败项列出具体原因

## 数据可信度

内置数据基准是 **2026-11-09**：8 座精选城整合自携程 / 同程 / 美团 / 墨迹天气公开页面，
其余为结构化攻略模板 + 官方检索入口，**未逐条抓取实时数据**。
自定义城市同理，票价、营业时间、预约状态请按「灵感来源」页出行前核对。
页面不会把任何估算值伪装成实时数据。
