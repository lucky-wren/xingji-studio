行迹 · 使用说明

完整行程工作台 + LibreTTS 微软神经音色的行程成片 · 可直接部署到 GitHub Pages 的静态站

01打开就能用

本地看：双击 index.html 即可打开完整工作台，36 座城市、衣食住行、逐日路线、游玩地图、视频合成全部可用。
上线：把整个目录 push 到 GitHub 仓库 → Settings → Pages → Source 选 GitHub Actions → Actions 跑一次「Deploy GitHub Pages」。

不需要装 Python、不需要装 ffmpeg、不需要跑 run.bat。这一版是纯静态站。

02人声：LibreTTS · 微软神经音色

切到「视频合成 06」，会看到浅绿色的 LibreTTS · 微软神经音色 卡片，只有三样：

控件作用
音色优先从 /api/voices?l=zh&f=1 拉中文音色；拉不到用内置 23 个常用中文音色
🔊 试听一句用成片同一个接口、同一个音色先听一句。只播一次，不写入音轨、不改时间轴、不触发合成
⬆ 逐句合成到人声轨逐句合成真实音频写进每一镜，按真实时长重排帧长 / 字幕 / SRT

接口地址、探测、调试 URL 等都不在界面上：config.js 里配置，页面启动自动选可用实例。语速 / 语调 / 并发同样在 config.js 里改。

03接口不给 CORS 怎么办（界面上不用填地址）

工作台界面上只有音色 / 试听一句 / 逐句合成到人声轨，没有地址输入框。页面启动会静默探测 config.js 里列出的实例，第一个可用就自动使用；全部不可用时，卡片上会出现一句提示和「查看解决办法」链接。

1
公共实例本身给了 CORS：什么都不用做，直接试听、合成。
2
本机使用：跑一次 python tools/bridge.py（默认 127.0.0.1:8790，启动探测会自动找到它），无需改任何配置。
3
想让任何访客打开网页就能合成：把 tools/cors-worker.js 部署成 Cloudflare Worker，然后把 Worker 地址写进 config.js 的 instances 数组，push 即可。页面不需要填地址。
隐私提醒：文案会经过 LibreTTS 公共实例服务器转发到微软。项目本身无数据库、不留存，但商用前请确认微软与实例方条款；隐私内容请自建实例或走本机桥。

04一键成片（同步是怎么保证的）

1
在字幕区逐句改文案 —— 字幕就是画面文案，也是朗读文案。
2
点「⬆ 逐句合成到人声轨」（或直接点唯一的生成按钮，它会先合成）。
3
每句音频的 AudioBuffer.duration 成为唯一事实来源，同时决定帧长、字幕窗口、SRT、音轨起点。
4
播放与导出只读一个主时钟，播放期间时间轴保持只读；改任何字幕 / 音色 / 语速都会让配音缓存失效重合成。
这和 B 站 / 剪映 一样：先有确定音频，再由它牵着画面和字幕走。浏览器系统嗓音彻底退出时间轴，不会再出现「话念完了画面没切」。

04.2新增城市 · 填名字就出完整行程

工作台里的城市不是写死在页面里的。侧栏点「⚙ 后台管理」→「＋ 新增城市」， 只填城市名就能生成完整行程，不用写 JSON。

步骤怎么做
① 填城市名只填这一项也能生成；其余留空系统自动补
② 贴落点一行一个景点名，可写 名称 | 区域 指定区域；写几个就够，不用凑满
③ 选天数 / 气候带决定排几天、穿什么；最多 7 天
④ 点「生成规划并添加」自动切到这座城、跳到路线页，弹窗里显示生成了几段内容
生成的是完整规划，不是空壳：逐日路线（每天都有真实安排）、衣食住行四象限、 地图落点、视频分镜与讲解词、封面标语全部一起生成。没填够的落点会用 【通用建议】 场景补足（如「老城街区 / 滨水步道 / 本地市集」）， 并明确标注不是具体景点名称，出行前请换成当地实际地点并核对开放信息。

「已添加的城市」里可以「切换到」「移除」「↓ 导出自定义城市 JSON」「↺ 恢复默认城市」。 新增只存在这台设备的浏览器里，刷新不丢；要让所有访客看到，把导出的 cities 数组并进 data/cities.js 的 extended 再部署即可。

要批量导入或精确控制每个字段，点弹窗第二个 tab「⚙ JSON 高级」，那里保留上传文件、 下载完整模板和逐条校验（字段说明见仓库 data/cities.schema.md）。 手写 JSON 只给少量景点时路线会出现留白，要完整行程请用向导。

04.3导航与侧栏

顶栏 ☰ 用于收起 / 展开目的地侧栏。

点顶部 6 个主标签，页面会滚到那块内容的顶部；顶栏「⌘ 快速跳转」下拉顶部会显示 「当前：路线规划」。点下拉里的「✍ 字幕 / 🧩 分镜 / 🎬 成片」，会先切到视频合成页、 再切到对应模块，最后把目标卡片滚到眼前并短暂高亮 —— 点了就能看到，不用自己找。

04.4右侧工具栏与音量

视频合成页是左边预览台 + 右边一整列：右侧栏顶部是 5 段工具栏（内容 / 字幕 / 声音 / 时间轴 / 导出）， 下面就是同一块参数面板。点哪段，只替换右侧同一位置的内容并滚动定位、回显「已定位」， 预览画面和播放器不会重建、播放不中断、页面也不会跳走。 面板头「⤡ 折叠本页」按模块记住状态，预览台上的「⌗ 专注」只收起参数面板、保留窄工具条，让画面铺宽。

「声音」页直接调总音量；人声与配乐音量收在「⚙ 更多」里，与试听、导出的成片是同一组数值， 不会出现「试听一个样、导出另一个样」。默认无配乐，需要时上传自己的音频文件；内置曲库与音效已不提供。 「🔊 试听当前混音」放的就是导出用的那条音轨。

04.5数据从哪来 · 怎么让全站生效

这是纯静态 GitHub Pages 站点，没有数据库、没有服务器。内容只在两个文件里：

文件管什么
data/cities.js36 座城市的全部素材：景点、美食、住宿、交通、分季穿搭、来源链接
config.js成片栏目结构（衣食住行各显示哪些字段、口播怎么拼）+ 人声接口配置

每一镜的画面文字行、字幕、SRT、人声朗读稿是同一份数据： 画面上画出来的每一行拼起来，就是字幕和朗读的文本。改字幕，画面和人声一起变。 弹窗「↓ 导出成片脚本 JSON」可以逐镜核对。

上线闭环：侧栏「＋ 城市数据」里改好 → 点「↓ 导出全站内容包 cities.js」→ 覆盖仓库的 data/cities.js → git push → GitHub Actions 自动重新部署 → 所有访客立即生效。本机改动只存浏览器 localStorage，不提交就只有你自己看得到。

完整说明：仓库里的 数据链路与内容配置.md 逐项写了字段设计、 buildRoute() 怎么排行程、sceneData() 怎么变成画面与字幕，以及导出的内容包如何自证没写死。

04.6配乐 / 音效 / 水印

模块能做什么
🎵 配乐6 首内置曲库（浏览器实时合成，不引入第三方录音），每首可先试听再选用；支持上传自己的音乐、调音量、人声响起时自动闪避
✨ 音效8 种内置音效、可上传自定义；设成「每次切镜」或只绑定到某几镜，按画面时间码混进成片音轨
🖋 水印文字或图片、九宫格定位、字号 / 颜色 / 描边 / 透明度 / 边距、斜向平铺防盗、显示范围；三套一键预设

水印是烧录进每一帧画面的：预览、WebM、PNG 分镜包、工程包帧图、GIF 全部自动带上，发布到平台也不会被剥掉。图片水印以 Data URL 内嵌进制作包 JSON，载入时自动还原。

上手建议：「画面」模块里先套一个「品牌角标」预设，改成自己的账号名；默认位置在右上，不会压住底部字幕板。

05导出

出口得到什么
⚡ 快速导出WebCodecs 非实时编码的 WebM（VP8/VP9 + Opus），自带人声与配乐，几秒出片
↓ 完整混音 WAV / SRT / 文稿人声 + 配乐音轨、按真实时长生成的字幕文件
↓ PNG 分镜包逐镜高清帧图 + 时间轴 JSON + SRT + 说明，可进剪映 / PR
↓ 制作包 JSON文案 + 接口/音色/语速 + 每镜真实时长
📺 仅字幕明确无配音，秒级出片

要通用 H.264/AAC MP4：把制作包和帧图放进 media/source/，在 Actions 跑「重建静态成品」。
