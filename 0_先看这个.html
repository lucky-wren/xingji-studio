XINGJI · STATIC WORKSPACE

行迹 · 先看这个

纯静态站点，无需服务器、无需数据库、无需构建命令。全部内容都在仓库里的文件，改文件 → 再跑一次 deploy.bat 即全站生效。

1 上线（只做一次：双击 → 粘 Token → 完事）

  1. 把本压缩包全部文件解压到一个空文件夹（index.html 和 deploy.bat 在同一层，不要套一层文件夹）。
  2. 第一次先在 TOKEN_GUIDE.html 生成一个 Token，勾 repo + workflow，复制那串 ghp_...。这一步是唯一一次需要打开 GitHub 网页。
  3. 双击 deploy.bat，粘贴 Token（输入不显示），回车。其余全自动：没有就建仓库 xingji-studio → 一次提交推完 → Pages 设为 GitHub Actions → 触发部署 → 打印网址。
  4. 等 1–3 分钟打开脚本给你的网址，收藏它。以后改完内容再双击一次即可，不用装 git、不用登录、不用记密码、不用手动选 Pages。

仍然想用 git 也完全可以：git add . && git commit -m init && git push，再去 Settings → Pages 把 Source 选成 GitHub Actions，两条路结果一样。 deploy.bat 只依赖 Python 3.8+（系统自带标准库，不用 pip 装东西），不修改你的 git 配置。

2 改城市内容（日常维护）

  1. 打开 admin.html（或工作台顶栏「⋯ 更多 → ⚙ 后台管理」/ 侧栏「⚙ 后台管理」）→ 列表 / 搜索 / 筛选 / 详情 / 编辑 / 新增 / 删除 / 恢复 / 导入 / 去重 / 🤖 AI 采编。
    城市数据集中在这里管理。点列表里的「详情」能看到该城全部字段，可直接修改保存；新增城市默认就带 12 落点 / 6 美食 / 3 住宿 / 4 交通，填名字即可，也可用 AI 一键检索生成。
  2. 右上角「↓ 导出 cities.full.js」与「↓ 导出 plan-config.js」→ 覆盖仓库 data/ 里的同名文件 → 再双击一次 deploy.bat（脚本只上传变化的文件，没变化就不提交）。
  3. 部署工作流会先跑数据硬校验：结构错误直接红灯不部署；内容提醒只打印。过了才发布，不会把坏站推上线。

后台里的改动会立刻在你这台电脑上预览（同源 localStorage 草稿），但只有导出并 push 才对所有访客生效。

3 数据与成片怎么来的

  1. data/national-cities.json：410 城行政区划事实层（名称 / 省份 / 大区）。
  2. data/cities.js：36 城真实快照；data/cities.full.js：410 城可直接出行程的完整字段（374 城为结构化通用框架）。
  3. data/plan-config.js：品牌、配色、图标、背景图、逐城视觉覆盖、隐藏城、自定义城。
  4. 成片工作台 film.html 用一张 durs[] 时间轴推导出帧数、SRT 时间码、人声起点与打字机进度；逐帧调用同一个绘制函数在浏览器内编码，产物只有 film.mp4。不播放一遍再录、不按墙钟等待。

4 生成一支成片

  1. 视频合成页底部点「✦ 导出成片」：当前页自动逐句合成人声、按 durs[] 逐帧编码，完成后直接下载 film.mp4，全程不跳页。
  2. 上方五段（内容 / 字幕 / 声音 / 时间轴 / 导出）点哪段，右侧同一块面板就定位到哪段；预览台始终原位，控制条横排在阶段时间轴上方。
  3. 改逐镜文案会即时重算时间轴；字幕可开关、字号字体颜色与位置可调，关闭时成片与 SRT 都不含字幕。
  4. 7 项硬校验全过才给下载。用 Chrome / Edge，通过 http(s):// 或 localhost 打开；需要手动调参时再打开下面的成片工作台。
